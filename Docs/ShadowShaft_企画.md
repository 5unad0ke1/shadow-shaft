# ShadowShaft 企画書

## 1. 概要

**ShadowShaft** は SunShaft(ゴッドレイ / 光芒)の逆をやるポストエフェクト。

- SunShaft:光が通る空間が明るく見える「光の筋」
- ShadowShaft:**影が落ちている空間が暗く見える「影の筋」**

遮蔽物(柱・木・窓枠・キャラクターなど)の影が、地面に落ちるだけでなく**空気中を貫く暗い帯**として見えるようにする。
カメラから各ピクセルへのレイ上をレイマーチングし、ライトのシャドウマップで「影の中にいる区間」を積算して、その分だけ画面を暗くする。

### 狙うビジュアル(スタイライズ寄り)

- 物理的なフォグの再現ではなく、**輪郭のはっきりした影の帯**を空間に描く
- 濃淡はグラデーションよりも段階的・くっきりめ(イラスト/アニメ調の影)
- 太陽が画面外にあっても成立する(スクリーンスペースの放射ブラー型 SunShaft との差別化ポイント)
- スポットライト・ポイントライトの影も、そのライトの照射範囲内で影の帯になる

## 4. 手法

### 4.1 処理の流れ

```
[不透明描画後のカメラカラー / 深度]
        │
        ▼
① ShadowShaft Pass(縮小解像度)
   ・深度からワールド座標を復元
   ・カメラ → 表面(or 最大距離)までレイマーチング
   ・各ステップで各ライトのシャドウマップをサンプル
   ・「影の濃さ」を積算 → 1ch テクスチャへ出力
        │
        ▼
② Blur Pass(深度考慮のバイラテラルブラー)
   ・ジッターによるノイズを除去
        │
        ▼
③ Composite Pass(フル解像度)
   ・深度考慮アップサンプル
   ・スタイライズ処理(しきい値・階調化)
   ・カメラカラーに影の濃さを合成(暗くする)
```

### 4.2 レイマーチング

各ピクセルについて、カメラ位置 `O` から方向 `D` へ、`t = 0 … tMax` を `N` ステップで進める。

```
tMax = min(シーン深度から求めた距離, MaxDistance)
```

各サンプル点 `x(t)` で、ライト `i` ごとに以下を評価する。

- `V_i(x)`:ライト i の可視性(シャドウマップ。0 = 影、1 = 日向)
- `A_i(x)`:ライト i がその点に届いているか(照射範囲の重み)
  - メインライト:常に 1
  - スポット:範囲端のスムーズな減衰 × コーン角減衰
  - ポイント:範囲端のスムーズな減衰
  - 距離の 2 乗減衰は使わない(ライト近くだけ極端に濃くならないように)
- `w_i`:ライトごとの寄与の重み
  - メインライト:`MainLightWeight`
  - 追加ライト:`AdditionalLightWeight × saturate(ライト色の輝度)`(明るさ 1 以上は同じ扱い)
- 追加ライトはレイとライト範囲(球)が交わる区間だけマーチする。刻みのグリッドはメインライトと共通

**影の濃さ(Darkness)** を次のように積算する。

```
ShadowLength = Σ_t Σ_i  w_i · A_i(x) · (1 - V_i(x)) · Δt     // レイ上で影に入っている区間の長さ
Darkness     = 1 - exp(-Density · ShadowLength)              // 0–1 に収める
```

影の区間が長いほど暗くなり、`Density` で「何 m 影に入ると十分暗くなるか」を調整する。

SunShaft なら `V` を積算して「明るさを足す」ところを、ShadowShaft では `1 - V` を積算して「暗さを引く」のが本質的な違い。
「ライトが届いていない場所」は `A_i = 0` なので暗くならない(=影ではなく単なる暗がりとして扱い、帯を作らない)。

スタイライズ寄りのため、物理的な透過率 `exp(-σt)` による遠方減衰は使わず、`DistanceFade`(距離でのフェード)で見た目を制御する。

### 4.3 スタイライズ処理

積算後の `Darkness` に対して見た目を整える。

```
x = min(saturate(Darkness * Intensity), MaxDarkness) / MaxDarkness   // 0-1 に正規化
lower = saturate(Threshold - Softness), upper = saturate(Threshold + Softness)
x = saturate((x - lower) / (upper - lower))                       // 帯の輪郭をくっきりさせる
x = Bands > 0 ? floor(x * Bands + 0.5) / Bands : x                  // 任意の階調化
d = x * MaxDarkness
```

- Threshold 0.5 / Softness 0.5 / Bands 0 で無変換(Phase 3 までと同じ見た目)
- ランプの両端を 0-1 に収めるので、影のない場所が暗くなったり、最大の暗さに届かなくなったりしない
- ランプ幅は最低でも約 1 ピクセル(fwidth)にして、Softness 0 でも輪郭がジャギにならないようにする
- 階調は MaxDarkness までの範囲を等分する(上限で潰れない)

### 4.4 合成(暗くするだけ)

```
finalColor = lerp(sceneColor, sceneColor * ShadowColor, d)
```

- 乗算ベースなので明るくなることはない
- `ShadowColor` で影に色味を付けられる(青紫系の影など、スタイライズ向け)
- `MaxDarkness` で最大でもどこまで暗くするかを制限

### 4.5 品質・負荷対策(PC 前提)

| 対策 | 内容 |
|---|---|
| 縮小解像度 | デフォルト 1/2 解像度でマーチング |
| ジッター | Interleaved Gradient Noise で開始位置をずらし、少ないステップ数でのバンディングを防ぐ |
| バイラテラルブラー | 深度差の大きい境界をまたがないブラーでノイズ除去 |
| 深度考慮アップサンプル | 物体の輪郭で影の筋が滲み出さないようにする |
| ライト数上限 | 影を積算する追加ライト数に上限を設ける(デフォルト 4) |
| 早期スキップ | 照射範囲(バウンディング球)とレイが交差しない追加ライトはマーチング対象から外す |

### 4.6 シャドウマップの扱い

**メインライト**
- URP の `TransformWorldToShadowCoord` + `MainLightRealtimeShadow` 系を使用
- カスケードシャドウ対応(カスケード境界での不連続に注意)
- Shadow Distance より先は影情報がないため、`MaxDistance` は Shadow Distance 以下に自動クランプする

**スポット / ポイントライト**
- URP の追加ライトシャドウアトラスを `AdditionalLightRealtimeShadow` 系でサンプル
- ポイントライトは 6 面(キューブ)がアトラスに並ぶため、方向から面を選ぶ処理が必要(URP 側の関数で対応)
- 影を落とす設定(Shadow Type が None 以外)のライトのみ対象
- Forward+ のクラスタは「表面のピクセル」基準でライトを絞り込むもので、レイ上の各点には使えない。そのため C# 側で対象ライト(可視ライトのインデックス)をリスト化してシェーダーに渡し、シェーダー内ではそのリストをループする

**共通**
- 空(深度が far)のピクセルは `MaxDistance` までマーチする

## 5. パラメータ(VolumeComponent)

| パラメータ | 型 | 説明 |
|---|---|---|
| Intensity | float | 全体の効きの強さ(0 で無効) |
| MaxDarkness | float (0–1) | 最大でどこまで暗くするか |
| ShadowColor | Color | 影部分に乗算する色 |
| Density | float | 影の区間長に対する濃くなりやすさ |
| Threshold | float (0–1) | 帯として見せ始める濃さのしきい値 |
| Softness | float (0–0.5) | 帯の輪郭のぼかし幅(0 でくっきり) |
| Bands | int | 階調数(0 で階調化なし) |
| MaxDistance | float | マーチングの最大距離 |
| DistanceFade | float (0–1) | MaxDistance の手前から帯を弱める範囲(MaxDistance に対する割合。0 でフェードなし) |
| StepCount | int | マーチングのステップ数 |
| MainLightWeight | float | メインライトの影の寄与 |
| AdditionalLightWeight | float | スポット/ポイントライトの影の寄与 |
| MaxAdditionalLights | int | 影を積算する追加ライトの上限 |
| Resolution | enum | レイマーチングとブラーの解像度(Full / Half / Quarter) |
| BlurIterations | int | 追加のぼかし回数(深度考慮の 5 タップガウシアン、縦横 1 往復で 1 回) |
| DepthThreshold | float | ブラーと拡大で同じ面とみなす深度差の割合 |

## 6. 開発フェーズ

### Phase 1:最小構成(メインライト)
- RendererFeature + フルスクリーンパス(フル解像度)
- 固定ステップのレイマーチング + メインライトのシャドウマップサンプル
- ワールド空間で一定の刻み幅(表面で途切れる最後の区間は長さを按分)
- インターリーブドサンプリング(4x4 Bayer で区間境界をずらす)+ 4x4 の深度考慮ブラー(Phase 3 から前倒し)
  - IGN ジッター単体ではブラーなしでディザ状のノイズが目立ったため不採用
  - 刻み幅一定だけでは StepCount 128 でもサンプル球の層が段差として見えた
- 縮小解像度(Full / Half / Quarter)+ 合成時の深度考慮アップサンプル(Phase 3 から前倒し)
- 乗算で暗くする合成
- VolumeComponent(基本パラメータのみ)

### Phase 2:追加ライト
- スポット / ポイントライトの影のサンプル(追加ライトのシャドウアトラスを直接比較サンプル)
- C# 側での対象ライトのリスト化(影ありのスポット / ポイントから、範囲がカメラに近い順に MaxAdditionalLights 個)
- 照射範囲による重み付けと、レイ × 範囲球の交差によるマーチ区間の限定

### Phase 3:品質
- 追加のぼかし(BlurIterations):深度考慮の 5 タップガウシアンを縦横に分けてかける
- 深度しきい値のパラメータ化(DepthThreshold)
- 深度の重みを 0/1 から段階的な減衰に変更(しきい値の半分までは 1、しきい値で 0)。拡大時の輪郭の段差を緩和
- ブラー系パスの入力を Blitter の _BlitTexture 経由に統一(同じマテリアルで複数回ブラーしても入力が混ざらない)

### Phase 4:スタイライズ
- しきい値 / Softness / 階調化(デフォルト値では無変換)
- DistanceFade:サンプルごとにカメラからの距離で寄与を減衰(MaxDarkness は Phase 1 で前倒し済み)
- Volume のパラメータを Darkening / Stylize / Raymarch / Lights / Quality に整理
- 最終的なデフォルト値はユーザー側の確認結果を見て決める

各フェーズの完了ごとにユーザー側で動作確認する。

## 7. 想定リスク

| リスク | 対策案 |
|---|---|
| ステップ数が少ないとバンディング | ジッター + ブラー(スタイライズの階調化で目立ちにくくもなる) |
| カスケード境界で影の帯が途切れる | カスケードブレンド、または境界付近でのフェード |
| シャドウ距離の外で効果が急に消える | DistanceFade でフェードアウト |
| 追加ライトが多いと負荷が線形に増える | ライト数上限 + 交差判定によるスキップ |
| ポイントライトのキューブ面境界での継ぎ目 | 面選択を URP の関数に任せ、継ぎ目が目立つ場合はブラーで緩和 |
| 追加ライトのシャドウ解像度が低い(Tier 256–1024)と帯がガタつく | ブラー + Softness で緩和 |
| 半透明物体は深度を持たない | 対象外とする |
